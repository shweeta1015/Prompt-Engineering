# Prompt Engineering

A collection of Prompt Engineering experiments, assignments, and projects exploring Large Language Models (LLMs), prompt design, temperature, token probabilities, fine-tuning, and AI-generated responses.

## Contents

 1. Token Log Probabilities
Understanding token probabilities and log probabilities in Large Language Models with code, outputs, and explanations.

2. Temperature and LLM Output
Experiment demonstrating how different temperature values affect the creativity, randomness, and consistency of LLM-generated responses.

3. Base Model vs Fine-Tuned Model
Comparison of a base language model and a fine-tuned model to understand differences in their generated responses and performance.

# Technologies Used

- Python
- Google Gemini API
- Large Language Models (LLMs)
- Prompt Engineering
- Jupyter Notebook

# Objective

The purpose of this repository is to document practical experiments and assignments related to Prompt Engineering and Large Language Models, including prompt design, model behavior, temperature sampling, token probabilities, and fine-tuning.
